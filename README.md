# Resume Analyzer 📄🔍

An AI-powered application designed to analyze resumes, compare them against job descriptions, and provide actionable feedback to improve ATS (Applicant Tracking System) compatibility and overall quality.

---

## ✨ Features

* **ATS Score Calculation:** Evaluates how well a resume matches a specific job description.
* **Keyword Matching:** Highlights missing or relevant skills and keywords.
* **Format & Structure Analysis:** Identifies potential formatting issues that might trip up ATS parsers.
* **Actionable Suggestions:** Provides direct recommendations to improve impact, clarity, and phrasing.

---

## 🛠️ Tech Stack

* **Language:** Python
* **NLP & Parser:** spaCy / NLTK / PyPDF2
* **Frontend/Framework:** Streamlit / Flask (adjust based on your setup)
